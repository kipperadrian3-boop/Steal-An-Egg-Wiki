A fast, lightweight, and factual **Monochrome (Black & White)** Wiki for the Roblox game **Steal an Egg**.

---

## 🗺️ Verified Content

- **10 Explorable Biomes**: Exact speed requirements, guardians, and pet rosters (Forest, Lake, Desert, Jungle, Snow, Volcano, Abyss Ocean, Prehistoric, Cosmic, Cherry Blossom).
- **All Pets Database**: 80 biome pets + 6 limited Brainrot store pets, with official base earnings and egg sources.
- **Egg Mutations**: Exact in-game multipliers (Silver 1.25x, Bloom 1.5x, Golden 2x, Rainbow 2.5x, Spirit Bloom 3x).
- **Interactive Multiplier Calculator**: Real-time income calculation ($/s, $/min, $/hr).
- **Codes Status**: Direct facts confirming no code system is currently present in-game.
